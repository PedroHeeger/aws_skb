# Learning Plan: <a href="./learning_plan">learning_plan</a>

### AWS <a href="../">aws   <img src="https://cdn.jsdelivr.net/gh/devicons/devicon@latest/icons/amazonwebservices/amazonwebservices-original-wordmark.svg" alt="aws" width="auto" height="25"></a>

O *Learning Plan* (Plano de Aprendizado) representa uma das principais categorias de capacitação disponibilizadas pelo **AWS Skill Builder**, a plataforma oficial de treinamento em nuvem da Amazon Web Services (AWS). Trata-se de trilhas estruturadas sobre um tema ou assunto específico, compostas pela integração de diversas atividades em que cada uma atua como pré-requisito para a conclusão do plano.

Os planos de aprendizado podem englobar atividades de diferentes categorias, como Digital Course, Digital Course with Lab, AWS Builder Labs, entre outras. As atividades variam desde níveis iniciais, de curta duração, até níveis avançados, que exigem muitas horas de estudo. Por conta dessa amplitude, os planos de aprendizado costumam ser os que demandam maior tempo de dedicação para a conclusão. O último item de um plano de aprendizado é geralmente uma avaliação nos moldes de um exame de certificação da AWS, contendo cerca de 50 a 60 questões, onde é necessário atingir um aproveitamento de 80% para aprovação. Em alguns casos, essa avaliação pode vir separada em dois planos distintos, ficando a avaliação isolada em um segundo plano enquanto todo o conteúdo restante permanece no primeiro.

Ao completar todos os pré-requisitos do plano, um certificado oficial é emitido para indicar sua conclusão. Muitos desses planos estão vinculados às **AWS Knowledge Badges**: para conquistá-las, não é necessário realizar o plano inteiro, bastando atingir os 80% na avaliação do plano. As AWS Knowledge Badges são emitidas por plataformas parceiras, como a **Credly**, atestando formalmente a absorção do conteúdo técnico abordado. As badges disponíveis para as trilhas podem ser consultadas neste [link](https://www.credly.com/organizations/amazon-web-services/collections/customer-learning-programs/badge_templates).

Dessa forma, com o objetivo de organizar este repositório, esta pasta foi criada para armazenar todos os learning plans realizados na plataforma AWS Skill Builder. Cada plano concluído é vinculado a uma subpasta com um código de identificação. Em cada subpasta, um README descreve o conteúdo do plano. Como nenhum conteúdo inédito é gerado exclusivamente para o plano, ele funciona essencialmente como um agregador, já que os materiais presentes nele pertencem a outras categorias. Logo, o README de cada plano feito atuará apenas como um direcionador para os conteúdos correspondentes. Os links para cada plano realizado são listados abaixo, distribuídos pelas respectivas áreas de conhecimento da AWS.
