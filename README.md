# Amazon Web Services (AWS)   <img src="https://cdn.jsdelivr.net/gh/devicons/devicon@latest/icons/amazonwebservices/amazonwebservices-original-wordmark.svg" alt="aws" width="auto" height="25">

Este repositório foi criado com o objetivo de centralizar todo o conteúdo que venho desenvolvendo durante meus estudos sobre a nuvem AWS, utilizando diversas plataformas oficiais de capacitação oferecidas pela própria Amazon.

Inicialmente, ele foi pensado para ser um repositório exclusivo para as atividades realizadas na plataforma AWS Skill Builder, uma das principais ferramentas de estudo da AWS. Inclusive, muitas outras plataformas de aprendizado da AWS utilizam conteúdos provenientes do Skill Builder. O nome do repositório, aws_skb, foi escolhido justamente em referência a essa plataforma.

O Skill Builder é organizado por categorias de treinamento, que serviram de base para a estrutura de pastas inicial deste repositório. Embora a plataforma passe por atualizações frequentes — com a criação, renomeação ou remoção de categorias —, optei por manter a estrutura original para preservar o histórico, aplicando apenas pequenos ajustes quando necessário.

Com o tempo, o repositório expandiu-se para além do Skill Builder, incorporando materiais de outras plataformas — como o AWS Educate — e conteúdos autorais desenvolvidos ao longo da minha jornada, com destaque para scripts de automação em PowerShell, Python e Terraform.
